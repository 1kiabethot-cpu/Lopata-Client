# LOPATA CLIENT — Android-лаунчер (v0.2.0)

Структура:
- `app/` — Kotlin + Jetpack Compose застосунок (компаньйон для PojavLauncher).
- `.github/workflows/build.yml` — збірка debug-APK у GitHub Actions.
- `mod/` — попередній Fabric-мод LOPATA CLIENT (HUD) без змін.

## Збірка APK
1. Створи репозиторій на GitHub, завантаж ВЕСЬ вміст цієї папки (включно з прихованою `.github`).
2. Вкладка Actions → Build APK → Run workflow (або автоматично після push).
3. Артефакт `lopata-launcher-debug-apk` → розпакуй → `app-debug.apk` → встанови на телефон
   (дозволь «встановлення з невідомих джерел»).

## Що реалізовано (код написано, НЕ зібрано й НЕ запущено)
- Головний екран, вкладки з анімацією, неонова тема.
- Профілі, локальний нік, список серверів.
- Вибір папки .minecraft (SAF), встановлення .jar-модів у mods/ та .zip-ресурспаків у resourcepacks/.
- Пресети оптимізації → options.txt (з резервною копією).
- Експорт серверів → servers.dat (з резервною копією).
- Кнопка відкриття PojavLauncher.

## Обмеження
- Автозапуску гри з профілем немає: публічного API у Pojav я не підтвердив.
- Нік не замінює Microsoft-авторизацію.
- Усе вище потребує перевірки на реальному телефоні.
